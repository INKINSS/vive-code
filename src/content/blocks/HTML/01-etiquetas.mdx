## concepto de etiquetas
HTML se caracteríza por trabajar con un concepto llamado **etiquetas**. existen decenas de etiquetas y cada una tiene su propia función y propósito de existir. Lo que nos interesa en este bloque es hacer énfasis en 3 aspectos: **estructura, atributos y tipos de etiquetas que existen**.

## estructura de una etiqueta
Las etiquetas tienen una estructura propia que comparten entre si. **Estas se estriben usando los signos de mayor y menor que**. dentro de estos signos se escribe el nombre de la etiqueta.

<img src="/01-etiqueta.svg" alt="etiqueta" />

La mayoría de las etiquetas tienen que tener una etiqueta de cierre, entonces se repite la etiqueta solo que esta vez con una barra diagonal en la etiqueta de cierre, dejando claro que es el cierre.

La mayoría de las etiquetas permiten almacenar contenido entre la etiqueta de apertura y cierre, aunque hay algunas que únicamente tienen una apertura y nada más. hablaremos de ellas más adelante.
