## concepto de etiquetas
HTML se caracteríza por trabajar con un concepto llamado **etiquetas**. existen decenas de etiquetas y cada una tiene su propia función y propósito de existir. Lo que nos interesa en esta sección es hacer énfasis en 3 aspectos: **la estructura, los atributos y los tipos de etiquetas que existen**.

## estructura de una etiqueta
Las etiquetas tienen una estructura propia que comparten entre si. Se escriben usando los signos de mayor y menor qué, **dentro de estos signos se escribe el nombre de la etiqueta**. Existen etiquetas que únicamente tienen una apertura y nada más, por lo que no requieren de una etiqueta de cierre.

_el siguiente ejemplo muestra la estructura de la etiqueta a_

<img src="/html/01-etiqueta.svg" alt="etiqueta" />

Esta etiqueta 'a' (que es abreviatura de anchor o ancla) tiene como propósito hacer un enlace entre la pagina actual con una página web de fuera, en la imagen se muestra la estructura que requiere esta etiqueta señalizada por colores

**color rojo:** etiqueta de apertura y de cierre <br />
**color amarillo:** atributo (en este caso 'href') <br />
**color verde:** valor asignado al atributo (en este caso 'https://google.com') <br />
**color negro:** contenido interno (en este caso 'contenido') <br />

Si quieres más información acerca de la etiqueta 'anchor' te dejo el siguiente enlace: <a className='text-customMainBlack' href="https://developer.mozilla.org/es/docs/Web/HTML/Reference/Elements/a">documentacion de etiqueta anchor</a>

Existen 2 tipos de estructura para las etiquetas, las que únicamente requieren de una apertura y nada más, por lo que no requieren de una etiqueta de cierre. Por otro lado, existen etiquetas que requieren de una etiqueta de cierre, por lo que se requiere de una etiqueta de apertura y una etiqueta de cierre. La etiqueta anchor (o 'a') es un claro ejemplo de una etiqueta que necesita de apertura y cierre. Por otro lado, existen etiquetas que únicamente requieren de una apertura y nada más (como la etiqueta img). este tipo de etiquetas tienen una estructura similar, la única diferencia es que se auto-cierran con una barra invertida al final de la etiqueta de apertura (veremos un ejemplo más delante).

## atributos de una etiqueta

Entre los atributos que permite la etiqueta anchor está el **href**, este contiene un anlace o fragmento de URL al cual apunta el enlace, en este ejemplo al buscador google. Pero no solo se limita a esto, también puede apuntar a una sección específica de una página web, o a un archivo local. En este ejemplo el enlace que visualizará el usuario será el texto “contenido”, que redigirá al usuario al buscador de google al hacer click, abriendo el buscador en la misma página, algo que puede mejorar todavía más si nuestra intención es abrir el enlace en una nueva pestaña. Para eso existe el atributo **target** para las etiquetas anchor. El atributo target recibe varios valores cuando lo utilizamos, el más conocido probablemente sea el valor de “**_blank**” para el caso de ser una etiqueta anchor, su función es cargar la URL en una nueva pestaña del navegador, esto es muy útil para cuando la intención no es cambiar el contenido previo a uno nuevo, sino dar un vistazo rápido al enlace.

Algo muy importante es agregar los atributos correctos a las etiquetas correctas, por ejemplo, la etiqueta anchor requiere de un atributo href para funcionar correctamente, por otro lado, la etiqueta h1 (heading 1, o encabezado 1) no requiere de ningún atributo para funcionar correctamente.

<img src="/html/03-etiqueta.svg" alt="etiqueta" />

La etiqueta h1 (heading 1 o encabezado 1) **sirve para dar un título principal a una página web**. Por lo general, solo se debe usa una vez por página y esta etiqueta no requiere de ningún atributo para funcionar correctamente. Existen 6 tipos de encabezados, desde el h1 (heading 1) hasta el h6 (heading 6), cada uno con su propia importancia y propósito y con mayor importancia entre ellos, por ejemplo, el h1 es el más importante y el h6 es el menos importante

## tipos de etiquetas

**Existen 2 tipos de etiquetas** (mencionadas anteriormente), las que únicamente requieren de una apertura y nada más y las que requieren de una etiqueta de apertura y una de cierre. Esta última ya las conoces, el ejemplo de la etiqueta anchor resumen muy bien el caso de las etiquetas que requieren de apertura y cierre, pero, ¿qué pasa con las etiquetas que únicamente requieren de una apertura y nada más?, ¿cómo se cierran estas etiquetas?. La etiqueta img (image o imagen) es un claro ejemplo de una etiqueta que únicamente requiere de una apertura y esta es su estructura

<img src="/html/02-etiqueta.svg" alt="etiqueta" />

En este ejemplo la etiqueta img únicamente requiere de una apertura, la manera de cerrar esta etiqueta es agregando una barra invertida al final de la etiqueta de apertura, esto es lo que se conoce como self-closing tag o etiqueta de auto-cierre. La razón de que existen las etiquetas de auto-cierre es porque no requieren de un contenido interno, o sea, no pueden almacenar otra etiqueta dentro de ellas. La etiqueta 'input' también es un buen ejemplo de otra etiqueta de auto-cierre, que su función es interactuar con el usuario y pedir información, ya sea un texto como nombres, apellidos, correos, también puede ser para ingresar una fecha. pero también cumple con la caracteristica de ser de auto-cierre.

Existen muchas etiquetas y cada una se usa para cubrir una necesidad, veremos las más utilizadas más delante, mientras tanto, quédate con la idea de que las etiquetas son el corazón del HTML, sin ellas, no se podría hacer la estructura de ninguna web.
