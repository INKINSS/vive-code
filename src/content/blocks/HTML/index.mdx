## ¿Qué es HTML?
HTML (Lenguaje de Marcado de Hipertexto, siglas en inglés) es la base y fundamento de la web como la conocemos hoy en día. este fundamento lo comparte juntamente con CSS (Hoja de Estilos en Cascada) y con Javascript (Lenguaje de Programación).

Este lenguaje de marcado define la estructura de cualquier web que conozcas. Su estructura se define por medio de **etiquetas** que pueden ser contenido plano como texto, o algo mucho más llamativo como **imágenes**, **videos**, **audios** entre otros.

Algo importante a remarcar es que HTML **no es un lenguaje de programación** sino un lenguaje de marcado, esto no lo hace menos importante, sino cumple una función distinta y muy importante, ser quien marca cómo estará estructurado tu proyecto

## un poco de historia
La primera versión de HTML apareció en el año 1991, **creado por Tim Berners-Lee**, en su lanzamiento existían solamente 18 elementos (etiquetas), de los cuales hoy en día se conservan 13, no fue hasta 1993 que se reconoció su potencial y hasta 1993 se trabajó en la segunda versión, llamada HTML+, en 1995 se lanzó la tercera versión llamada HTML 3.0 y sus versiones siguientes (HTML 3.1 y 3.2) fueron un gran éxito en los navegadores web NetScape y Mosaic. En el año 1997 se lanzó la cuarta versión HTML 4.0 ya como recomendación de W3C (World Wide Web Consortium) y **finalmente en 2006 se lanzó la quinta versión HTML5 que es la que conocemos hoy en día.**

**HTML5 ya es un estándar** presentada por W3C y el creador Tim Berners-Lee, presentado el 27 de octubre de 2014 como la versión más reciente y actual de HTML, su propósito es ser un lenguaje de marcado que permita la creación de contenido web de manera sencilla y accesible para todos los usuarios conbinado con CSS y Javascript**
